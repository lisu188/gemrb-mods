# Changelog

## 0.1.0

- Added six Psion discipline class rows with dynamically allocated IDs.
- Added compatibility with released combined and development split GemRB class
  table layouts.
- Added D&D 3e power-point and powers-known progressions through level 20.
- Added a persistent shared PP reserve based on actor stat 239.
- Added Intelligence-based bonus power points.
- Added PP restoration hooks for normal and temple resting.
- Added discipline, power, skill and feat metadata tables.
- Added six discipline-specific CLAB progressions.
- Added 60 level 1–5 prototype power resources.
- Added a cross-platform GemRB GUIScript patcher with backups and uninstall.
- Added static validation for tables, CLAB references and Python syntax.
- Documented current prototype limitations and development priorities.
